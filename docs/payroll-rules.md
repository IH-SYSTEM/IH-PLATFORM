# 勤怠から給与への計算ルール（2026-10-08 黒田さんと一問一答で決定）

Airシフトでの勤怠・給与計算を置き換えるためのルール。迷ったらここを正とする。変えるときは日付と理由を残す。

| # | 項目 | 決定 |
|---|---|---|
| 1 | 打刻の丸め | 15分単位。出勤は切り上げ、退勤は切り捨て ※退勤の切り捨ては違法と判断されるリスクあり（社労士に確認推奨） |
| 2〜5 | 残業の数え方 | 飲食店（一鴻・「一」・根っこ・obanzai）は1週間単位の非定型的変形労働時間制：前週までに知らせたその日のシフト時間（8時間以下なら8時間）を超えた分＋週40時間を超えた分が残業。美容室・本部・STYLE-US は法定どおり：1日8時間超＋週40時間超 |
| 6 | 深夜割増 | 22時〜翌5時に働いた分は全員 ×1.25（給与明細に「深夜割増」の内訳） |
| 7 | 休憩 | 退勤時に本人が入力した実績を引く。法定の最低限（6時間超45分・8時間超60分）に足りなければ本部・店長に知らせる |
| 8 | 早出 | シフト開始時刻から数える（早く来た分は払わない。指示して働かせた日は打刻修正） |
| 9 | 延長 | シフト終了後も打刻どおり払う（丸め後）。残業・深夜に当たれば割増 |
| 10 | 遅刻・早退 | 働いた分だけ払い、回数と分数を数えて給与入力の「遅刻」「早退」へ。罰金はしない |
| 11 | 締め・支払 | 月末締め・翌月25日払い（全社共通）。勤怠は営業日（朝6時切り替え）の1日〜月末 |
| 12〜13 | 時給の人の有給の金額 | 一律5時間 × 時給（月給・日給の人は給与が変わらない） ※就業規則への記載が必要 |
| 14 | 有給の付与 | 人ごとに入社日から（6か月後、以後毎年。出勤率8割・週の出勤日数による比例付与は勤怠から自動計算） |
| 15 | 月給の時間単価 | 月給 ÷ 173時間 |
| 16 | みなし残業 | 打ち分けは壁打ちセッションで決める。システムは人ごとに「みなし時間・金額」を登録し、超えた分を自動計算できる形にする |
| 17 | 36協定 | 特別条項なし（月45時間・年360時間）。月40時間で注意、45時間で警告（本人・店長・本部） |
| 18 | 休日出勤 | 週（月〜日）に1日も休みがないときだけ、最後の勤務日を法定休日として ×1.35 |
| 19 | 日給の時間単価 | 日給 ÷ 8時間 |
| 20 | 給与入力への反映 | 経理が「勤怠から取り込む」ボタンを押したときに取り込む（自動では入れない） |

## 社労士・税理士に確認しておくこと
- 1：退勤の15分切り捨て
- 2〜5：1週間単位の変形の労使協定の届出、常時30人未満の要件、前週までの書面通知（シフト確定の通知で足りるか）
- 12〜13：有給の賃金（一律5時間）の就業規則への記載
- 16：みなし残業の契約上の書き方
