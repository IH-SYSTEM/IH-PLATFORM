# IH-PLATFORM ロードマップ（2026-10-08 黒田さんが残した機能）

申請・届出・現場の報告は、すべて報告窓口（`lib/reports`）の仕組みに「種類」を足して作る。入力欄を決め、承認したら自動で反映し、LINEで知らせる。

## 先に作る土台（これがないと後の機能が作れない・作り直しになる）
| 土台 | 必要になる機能 |
|---|---|
| 法人（会社）マスタと、店舗→法人の紐付け | 法定三帳簿、源泉徴収票、年末調整、経費（どの会社の経費か） |
| 権限のモジュール方式（役割テンプレート＋個人ごとのON/OFF、範囲） | 経理・総務の分担、ハラスメント窓口（限られた人だけが見る）、承認者の設定 |
| 承認者の設定（種類・金額ごと、多段階） | 経費・備品・出張・稟議 |
| ファイル添付（非公開ストレージ、閲覧できる人を限定） | 経費の領収書、マイナンバー・扶養の書類、雇用契約書、源泉徴収票 |
| 操作ログ（誰が何を見た・変えたか） | マイナンバー（法令上の安全管理措置）、給与・勤怠の監査 |
| 有給の付与データ（付与日・日数・残日数の初期値） | 有給の残日数、有給申請、有給5日取得義務のアラート |

## 段階
### 第0段階：10/15 並行運用まで
- トップのUI（役割別「今日やること」、スマホは下のバー、PCはタブ付きメニュー）
- 一鴻スタッフのLINE連携
- LINE通知の鍵（Messaging API のアクセストークン）を本番に設定

### 第1段階：11/1 本格運用まで（年末調整を優先するため、届け・交代申請は11月中に後ろへずらしてよい）
- 欠勤・遅刻・早退の届け、シフト変更・交代申請
- 自分の勤怠・残業時間
- お知らせ（既読管理）
- 法人マスタ、権限のモジュール方式
- 現場からの報告（事故・ヒヤリハット、設備故障、レジ差異、クレーム、目安箱）※種類を足すだけ

### 第2段階：11月（年末調整の山）
- 年末調整のオンライン提出（扶養控除・保険料控除などの申告書を集める。税額の計算は既存の方法または税理士）※2026-10-08 黒田さん決定：今年（2026年分）から行う
  - 予定：〜10/20 法人マスタ・ファイル添付・操作ログ／〜11/9 申告書の入力画面と本部の確認画面／11/10〜11/25 従業員が提出／〜12/5 本部が確認し、計算用に書き出し／12月の給与で精算
  - 1年目はマイナンバーの入力を画面に入れない（会社が扶養親族の番号を別に管理していれば省略できる運用。法令の扱いは税理士に確認）
  - 申告書の様式は、その年の国税庁の最新版に合わせる（2025年改正で基礎控除・特定親族特別控除が変わっている）
- 扶養異動届、住所・氏名変更届、通勤経路変更届、プロフィール変更申請
- 口座・扶養・マイナンバーの提出（ファイル添付と操作ログが前提）
- 有給の付与データ登録 → 有給の残日数、有給休暇申請、特別休暇（慶弔）申請

### 第3段階：12〜1月
- 経費精算、交通費・立替金精算、備品購入申請、出張申請、承認者の設定、稟議
- 法定三帳簿の出力（労働者名簿は既存。賃金台帳・出勤簿を追加）
- 残業の上限アラート（36協定）、有給5日取得義務のアラート（勤怠が貯まってから）
- 源泉徴収票の閲覧・ダウンロード（1月の交付に合わせる）
- 残業の事前申請、証明書の発行依頼

### 第4段階：2月以降
- ハラスメント相談窓口（閲覧者を限定する権限が前提）
- 雇用契約書・労働条件通知書の閲覧、入社手続きのオンライン化
- 健康診断・ストレスチェックの管理、資格・免許の期限管理
- 就業規則・マニュアルの閲覧、社内カレンダー、社員名簿・連絡網
- 等級と時給表、目標設定・評価面談の記録、研修・動画マニュアルの受講管理
- 人件費率ダッシュボード（売上データの取り込みが前提）、操作ログの閲覧画面、契約書・取引先の管理
